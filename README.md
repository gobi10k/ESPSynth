# ESP32 Synthesizer v5

A full-featured polyphonic synthesis engine for ESP32.

## Key Features
- 4-voice polyphony
- Multi-page UI
- Full effects chain (Reverb, Delay, Chorus, etc.)
- SD Card preset storage
- Hardware MIDI & Analog controls
